Lístkomat 2.4 — what changed in this update:
• The Brno live map moved to a new upstream data source again — the public
  KORDIS stream this app used (stream_kordis_26) went silent without notice on
  2026-08-29, so the app now reads the operator's current stream (Kordis_stream).
• Prague metro markers are coloured by line, using the network's official line
  colours (A green, B yellow, C red).
• Fixed a bug where the "Potvrdit nyní" ("Confirm now") button on a pending
  ticket needed two taps.
• Added an informational note explaining that buying a ticket requires a Czech
  operator's SIM. It informs only — it never blocks a purchase.

Purchase mechanism is UNCHANGED from previous approved versions: a ticket is
bought by sending a carrier-billed premium SMS (price = ticket price), which
requires a Czech SIM. A reviewer on a foreign SIM or without a SIM cannot
complete a purchase — this is expected and not a bug. No in-app purchase applies
(this is a real-world public-transport ticket billed by the carrier).

The live map uses open, CC-BY-licensed public transit data (Prague: Operátor ICT /
Golemio PID; Brno: data.Brno / KORDIS JMK), fetched via a small caching proxy that
holds the data key. The map needs no account, no purchase, and no SIM — a reviewer
can open any city's "Živá mapa" to see it working. Prague's map is the quickest
way to see this release's visible change: the metro markers are now green, yellow
and red by line.
